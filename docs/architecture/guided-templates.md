# Guided templates

Moved verbatim from `CLAUDE.md`. Paths in links are relative to this folder.

### Guided templates

A workout can be **guided**: instead of assignments it carries `WorkoutTemplate.steps`, a list of `GuidedStep` (`name`, `seconds`, optional `bothSides`, `hint`, `transitionSeconds`, `spokenName`) that the app will play through by time alone — no reps, sets or load. Guided is independent of `category`. Steps are plain values on the template, like `scheduledWeekdays`, so there is no table; only the library import writes them, and it replaces the list whole. A guided template has **no assignments** (the import refuses both). `isGuidedTemplate` ([guided-steps.ts](../../src/domain/guided-steps.ts)) is the one test for it.

**`resolveGuidedSections(steps)` is the one place steps become a timeline** — the later start screen, progress bar, announcements and run all read its flat `GuidedSection[]` and never recompute from the steps. Each section is `{ kind: 'transition' | 'exercise' | 'sideSwitch', stepIndex, side?, seconds, startSeconds }`: a 5 s transition before the first step (fixed, whatever that step's own `transitionSeconds` says), then each further step's `transitionSeconds` (default 5) before it, and a `bothSides` step becomes left, a 3 s side switch, right, each half the full `seconds`. A transition and a side switch carry the `side` of the exercise they lead into and belong to that step. Nothing follows the last step: the end is an event, not a section. `describeGuidedFacts` / `describeGuidedStepDuration` are the start screen's strings; `loadTemplateMinutes` / `loadTemplateExerciseCounts` take their numbers for a guided template from the sections and the steps. `startSessionFromTemplate` refuses a guided template — it would materialize an empty strength session — so the UIs go to `/guided/:templateId` through `navigateToGuidedStart` ([session-navigation.ts](../../src/lib/session-navigation.ts); it hands the plan entry over as router state and `readGuidedStartState` reads it back).

**The guided stage is fixed landscape, light for the start screen and dark for the run.** [GuidedStage.tsx](../../src/components/GuidedStage.tsx) is the full-screen frame every screen of a guided session stands on, with `tone="light"` (default: paper ground, `theme-color` untouched — the start screen) or `tone="dark"` (ink ground, `applyThemeColor(INK_THEME_COLOR)` like the rest mode, restored on unmount — the screens of the running session, from the run ticket on). Dark is the **second dark exception** to the single-theme rule, next to the rest mode, and for the same reason (screen on for minutes, OLED); only what runs is dark, never the start screen. The stage is the **inverse of the portrait lock**: `.guided-stage` in [index.css](../../src/index.css) fills the page in landscape and rotates 90° with swapped `100dvh`/`100dvw` in portrait on a coarse-pointer phone. It is a **portal into `body`, not a child of `#root`** — in landscape the lock rotates `#root` back to portrait, and anything inside would stand upright again (`RestMode` and `Sheet` are portals for the same reason). Its content reads only `--stage-inset-*`, the safe-area insets as seen from the stage (left edge = device top when rotated); the hint dialog ([GuidedHintDialog.tsx](../../src/components/GuidedHintDialog.tsx), an ink card over a scrim in both tones) lies *inside* the stage for the same reason and is not a `Sheet`. The rotation direction is a fixed assumption (clockwise): iOS's orientation lock cannot be detected, and `data-screen-angle` only exists in landscape. At most one lime surface per screen: none on the start screen, since nothing is up next yet, and its start button is ink. [GuidedStartPage.tsx](../../src/pages/GuidedStartPage.tsx) is the start screen (steps left on `surface-sunken`, facts as one sideways-scrolling row of pills right); the button is still disabled — the run is a later ticket. On `TemplateDetailPage` a guided workout shows its steps read-only (`GuidedStepsCard`) with a link to the start screen, and no exercise or assignment editing: a guided template has no assignments. Test anchors: `data-guided-stage` (the screen: `start`, `loading`, `missing`) with `data-guided-tone`, `data-guided-template`, `data-guided-steps`, `data-guided-step`, `data-guided-facts`, `data-guided-hint`; [guided-start.spec.ts](../../e2e/guided-start.spec.ts) reads them.
